## Discovery and HTML fallbacks

- **Known-source URL mapping should precede generic HTML discovery.** The direct OpenAI news HTML request returned **403** while its RSS returned **200**. DeepMind's blog HTML returned 200 but advertised no RSS alternate link. Seed the verified URLs above so these defaults do not depend on discovery succeeding. ([OpenAI endpoint](https://openai.com/news/rss.xml), [DeepMind listing](https://deepmind.google/blog/))
- **Thinking Machines:** its [homepage](https://thinkingmachines.ai/) advertises `/index.xml`; its [blog](https://thinkingmachines.ai/blog/) advertises [`/blog/index.xml`](https://thinkingmachines.ai/blog/index.xml), also verified 200/RSS 2.0 with the same seven article URLs. Emergency HTML extraction can use `a.post-item-link`, descendant `h2.post-title`, `.author-date`, and `time[datetime]` (ISO date). The CSS class named `author-date` held the author text in this snapshot.
- **Hugging Face:** [blog HTML](https://huggingface.co/blog) advertises the relative `/blog/feed.xml`; resolve against the final page URL. Server-rendered cards include `article`, an article link containing `h4`, and `time[datetime]`. The page also includes community cards; do not assume HTML scraping reproduces exactly the feed's editorial scope.
- **DeepMind:** [blog HTML](https://deepmind.google/blog/) contains `.card.card-blog`, `.card__title`, `a.card__overlay-link[href]`, image `src`, and `time`. The observed card date was only **month/year**, so prefer the RSS publication timestamp and avoid inventing a day from this fallback.
- **OpenAI:** no reliable HTML fallback was established because the listing fetch was denied. Report a feed error and retry later if RSS fails; the feed itself is the verified ingestion path.

### Anthropic: recommended named parser

The [news listing](https://www.anthropic.com/news) delivered **24 server-rendered `li[data-listing-row]` records** under `main`, with a heading link, description paragraph, and `<time>` text such as `Oct 22, 2026`. Each record repeats content for expanded/mobile presentation. The HTML contains Next.js flight scripts, **no `__NEXT_DATA__` script**, and generated CSS class names; neither framework internals nor exact class hashes are a good primary parser contract.

Recommended extraction with `golang.org/x/net/html`:

1. Find `main`, then `li` elements with `data-listing-row`. Within each row, choose the first `h3` and its ancestor `a[href]` as title/URL; the first matching article-link paragraph as description; the first `time` as publication date. Prefer `datetime` if supplied; currently the listing dates require parsing `Jan 2, 2006`. Represent date-only values as midnight UTC under the API's RFC3339 convention.
2. Resolve URLs against the final response URL, require the expected first-party origin, and deduplicate canonical article URLs. **Do not require `/news/` paths:** observed rows also link to `/claude-haiku-5-5`, `/claude-opus-5-5`, `/claude-sonnet-5-5`, and `/features/ebola-response`. Broad `/news/*` anchor scraping also picks up category navigation and duplicate links.
3. Use the listing data for ordinary syncs. For optional enrichment of new/saved items, this [verified article](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation) contains `application/ld+json` **NewsArticle** with `headline`, specific `description`, `datePublished`, `dateModified`, organization author, and canonical URL; also `article:published_time`, `link[rel=canonical]`, `time[datetime]`, and `og:image`. Prefer JSON-LD description over the observed generic organization description in `og:description`. The image may be a generic brand image.
4. Treat zero valid rows as a parser error, preserve existing inbox records, and expose `last_error`. A semantic backup can locate the section headed “All news” and process list rows containing heading links plus dates. Do not silently fall back to collecting every site link.

The [official sitemap](https://www.anthropic.com/sitemap.xml) also returned **200/application/xml**: a namespaced `urlset` with 576 locations, 278 under `/news/`, and `lastmod` timestamps. It can support later backfill with article metadata validation, but **`lastmod` is not publication time**, and news also has top-level URLs. The listing exposes “See more”; pagination/backfill was not verified. The initial parser can cover its 24 delivered rows without reverse engineering a private API.

## Go ingestion recommendations

- Use the contract's [gofeed](https://github.com/mmcdole/gofeed) for RSS/Atom normalization; it supports both formats and extensions. Fetch with the app's bounded, timeout-equipped HTTP client, then call its reader parser so source fetches share the required private-address and redirect protections. Use the contract's [HTML5 parser](https://pkg.go.dev/golang.org/x/net/html) for discovery and the named Anthropic adapter; no browser dependency is needed for observed pages.
- Resolve HTML alternate links for both `application/rss+xml` and `application/atom+xml`, validate the downloaded feed, and persist the actual feed endpoint. Recognize XML served as `text/xml` or `application/xml`; do not require an RSS-specific MIME type. Reject unsupported HTML sources clearly, as the contract requires.
- Normalize dates through parsed timestamps, map article link to URL, and use durable canonical URL uniqueness. Prefer feed author when present; otherwise keep it empty or explicitly use the publisher as a publisher fallback. Never derive an author from the GUID. Missing descriptions and covers are expected, especially for Hugging Face.
- Prefer description, otherwise extract a short **plain-text** excerpt from `content:encoded` (important for Thinking Machines). Map Media RSS thumbnails for DeepMind. Render remote text safely; full feed HTML should not flow unfiltered into React.
- Allow feeds larger than 1 MiB: Thinking Machines was **1,107,360 bytes**, OpenAI **801,758**, Hugging Face **262,933**, and decoded DeepMind **69,185**. A bounded decompressed limit such as 8 MiB is a reasonable starting recommendation. Let [Go's HTTP transport](https://pkg.go.dev/net/http#Transport) manage gzip negotiation/decompression by default; explicitly setting `Accept-Encoding` changes its automatic behavior. Avoid copying the raw compressed DeepMind bytes into an XML parser.
- A **60-minute** default interval matches the contract. Thinking Machines, DeepMind, and Hugging Face supplied ETags; conditional requests can be added without changing the API contract. Keep failures independent per source, preserve existing user state during resync, and expose sync errors.
