# Product direction — 2026-11-07

Margin's primary job is to help its owner choose something saved to read, watch, or play. The library overview should make those choices easy to recognize and compare. Saving, finding, and finishing items support that job; collecting more material is secondary.

The owner's stated preference is a compact Mixed or Shelves overview with a way to prioritize selected resources. Library is the default. Up next is an optional ordered subset within Library, using the same layouts.

## Criteria for changes

1. **Choosing:** Does the change make it easier to recognize and open a saved item? Artwork, title, and type should remain easy to scan.
2. **Density:** Does the overview show useful choices without large instructions or permanent action panels? Extra controls should appear where they are needed.
3. **Deliberate priority:** Can the owner select and order a few items without having to organize the entire library? Saving, prioritizing, and completing remain separate actions.
4. **Low maintenance:** Does a routine save work without a second review task? Attention flags should identify a concrete problem.
5. **Trust:** Do saved items and priorities survive reloads and concurrent edits? Removal from Up next keeps the item; completion and deletion clean up membership; private priority stays private.
6. **Access:** Can the same flow be used on a narrow phone and with the keyboard? Focus, names, errors, and touch targets matter as much as visual compactness.
7. **Scope:** Is the benefit worth another setting, concept, dependency, or background process? Prefer adapting the current library to adding a new destination.

## Current changes

The library retains Mixed, Shelves, and List. Up next appears among its filters, with discreet global ranks and contextual add/reorder/remove actions. Direct browser and integration saves no longer enter routine review; unresolved identity problems still need attention. Discover, source collection, public sharing, and integrations retain their current behavior.

Further simplification should start with the library toolbar and low-use settings, assessed against the criteria above. Removing collection or sharing would be a separate product decision, informed by actual use.
